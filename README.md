# 🧮 EasyMultiply - Онлайн Тренажёр Таблицы Умножения

**Попробуйте онлайн**: [https://easymultiply.com/](https://easymultiply.com/)

##  Описание

EasyMultiply — это веб-приложение для эффективного изучения таблицы умножения. Основано на методе многократного повторения: чем чаще вы решаете одни и те же примеры, тем лучше запоминаете результат.

##  Принцип работы

1. **Первый раз** — вы считаете ответ
2. **Второй раз** — снова считаете
3. **Последующие разы** — вспоминаете ответ: "Я же недавно решал этот пример!"

- 🎯 **Настраиваемые сессии** — выбор конкретных чисел для изучения
- 🏆 **Система достижений** — мотивационные элементы
- 📱 **Адаптивность** — работает на всех устройствах
- 🚀 **Быстрая загрузка** — оптимизированная сборка с Vite

- ✅ **Научно обоснованный подход** — метод интервального повторения

## Пошаговая инструкция

1. **Выберите числа** — кликните на числа от 0 до 10, умножение на которые хотите изучить
2. **Установите цель** — введите количество правильных ответов (рекомендуется 100)
3. **Начните тренировку** — нажмите кнопку "Старт"
4. **Решайте примеры** — вводите ответы и нажимайте "=" или Enter
5. **Отслеживайте прогресс** — следите за статистикой в нижней части экрана

## Интерфейс

```
[Число] × [Число] = [Ваш ответ]
```

- **Зелёная подсветка** — правильный ответ
- **Красная подсветка** — неправильный ответ
- **Статистика** — общие/успешные/неудачные попытки

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/evakerrigan/multi.git

# Перейдите в директорию проекта
cd multi

# Установите зависимости
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000`

### Сборка для продакшена

```bash
npm run build
```

### Предварительный просмотр сборки

```bash
npm run serve
```
